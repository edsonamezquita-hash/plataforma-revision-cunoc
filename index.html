Conectar con Google

Para guardar en Drive y enviar por correo desde su propia cuenta, necesita un ID de cliente OAuth gratuito de Google (una sola vez, suyo, no se comparte con nadie):
  1. Entre a console.cloud.google.com/apis/credentials
  2. Cree un proyecto → "Crear credenciales" → "ID de cliente de OAuth" → tipo "Aplicación web"
  3. En "Orígenes autorizados de JavaScript" agrega la URL desde la que abres esta app
  4. Habilite la Google Drive API y la Gmail API, y copie también una "Clave de API" (API key)
Aún no se ha conectado ninguna cuenta.
